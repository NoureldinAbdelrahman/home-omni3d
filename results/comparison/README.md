# results/comparison (MS1)

Everything in this folder is **MS1 material** generated by `notebooks/dataset_analysis.ipynb` at tag `milestone-1`. It is not the MS2 comparison.

- `metrics_table.csv`: six MS1 Pix2Vox runs, five MS1 AtlasNet-SVR runs and the 24-object NeRF oracle. The AtlasNet "F-score" column uses τ² = 0.001 on squared distances (see [`docs/METRICS.md`](../../docs/METRICS.md#the-scales-in-use)). These runs were trained before the point-cloud pairing fix. The file name is kept because the notebook writes it and the MS2 outline cites `main:results/comparison/metrics_table.csv`.
- `figures/`: MS1 dataset and run figures. `figures/dataset_examples.png` is used on MS2 slide 4; `figures/qualitative/*_compare.png` are not used in MS2.

The MS2 cross-track index is [`results/README.md`](../README.md). It lists each track with its own protocol; there is no merged MS2 table, because the tracks are not directly comparable.
